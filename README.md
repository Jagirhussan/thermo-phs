## Overview

This repository contains the complete simulation code, figure-generation scripts, and parameter documentation for

> Hussan, J. R., Omholt, S. W., and Hunter, P. J. "Guaranteeing thermodynamically consistent multiphysics modeling by use of port-Hamiltonian hypergraphs" (2025).

The framework integrates port-Hamiltonian systems theory with hypergraph representations of interaction networks to guarantee that multiphysics computational physiology models are thermodynamically consistent — strictly preventing non-physical energy generation and numerical drift — while maintaining computational efficiency that scales linearly with system size.

The codebase supports three core demonstrations described in the manuscript:

1.  **Validation of the hypergraph Laplacian** in a 3-cell electromechanical cluster, showing numerical equivalence between the O(N²) dense-matrix solver and the O(N) hypergraph Laplacian solver (Figure 1, Figure S1).

2.  **Thermodynamic profiling of myocardial fibrosis**, revealing how metabolic autoregulation masks the true energetic cost of wave propagation through scar tissue (Figures 3, S2, S3).

3.  **Algorithmic scalability in 3D anisotropic ventricular wedges**, demonstrating sub-linear wall-clock scaling up to 2.0 million nodes and the super-linear thermodynamic gain of larger tissue volumes (Figure 2).

4.  **Autonomic regulation via control by interconnection**, implementing a dual-mode sympathetic neuro-controller that modulates inotropy and metabolism strictly through power-conserving parameter routing (Figure 4).

## Reproducing the Figures

All figure scripts are self-contained and can be run independently.  Output is written to the `figures/` directory.

### Figure 1 — Hypergraph Laplacian validation (3-cell cluster)

```bash
python Figure1.py
```

Produces `figures/panel_a.pdf` through `figures/panel_f.pdf`.  Runtime: approximately 10 seconds.  No external data required.

### Figure S1 — FCU internal consistency audit

```bash
python FigureS1.py
```

Produces `figures/S1.pdf`.  Runtime: approximately 5 seconds.  No external data required.

### Figures 3 and S3 — Thermodynamic profiling of fibrosis

These figures require the ensemble simulation data generated by `run_experiment_ensemble.py`.

**Step 1: Run the ensemble** (computationally expensive; approximately 2–6 hours on 8–16 cores):

```bash
python run_experiment_ensemble.py
```

This creates `results_thermo_audit/` with 152 individual simulation runs (1 healthy + 50 diffuse + 50 patchy, each in planar and spiral protocols).

**Step 2: Generate the figures:**

```bash
python Figure3.py    # → figures/Figure3_panel_1.pdf, Figure3_panel_2.pdf
python FigureS3.py   # → figures/S3.pdf
```

### Figure S2 — Fibrosis tissue structure

```bash
python FigureS2.py   # → figures/S2.pdf
```

No external data required.  Runtime: approximately 2 seconds.

### Figure 4 — Autonomic control

```bash
python Figure4.py    # → figures/Figure4.pdf
```

No external data required.  Runtime: approximately 30 seconds.

### Figure 2 — 3D scalability and thermodynamic gain

Figure 2 requires data from the 3D ventricular wedge scaling studies.  These are the most computationally expensive simulations in the repository.

**Step 1: Run the scaling studies** (each preset takes 1.5–11 hours on a modern CPU):

```bash
# Individual preset:
python scaling_studies/run_scaling_study.py --preset 250

# All seven presets (for the complete figure):
for preset in 140x2 160x2 150_cons 163 175 200 250; do
    python scaling_studies/run_scaling_study.py --preset $preset
done

# List all available presets:
python scaling_studies/run_scaling_study.py --list-presets
```

Each run creates a directory `scaling_studies/scaling_study_{preset}/` containing the energy log and optional VTK output.

**Step 2: Generate the figure:**

```bash
python Figure2.py    # → figures/Fig2_Panel_A.pdf, Fig2_Panel_B.pdf, Fig2_Panel_D.pdf
```

### 3D spiral wave visualisation (supplementary)

```bash
python scaling_studies/plot_3d_animation.py
```

Requires VTK output from a scaling study run.  Produces `threeD_spiral_audit.mp4`.

## Key Modelling Components

### Aliev-Panfilov electrophysiology

A phenomenological two-variable reduction of cardiac excitation dynamics (Aliev and Panfilov, 1996).  Captures the essential non-linear behaviour of action-potential initiation, plateau, and repolarisation while remaining computationally tractable for tissue-scale simulations.

### Nash-Panfilov / Silva active mechanics

Extends the electrical model with calcium activation (T_ai) and active tension (T_a) variables, reproducing the biological delay between electrical stimulus and sarcomere contraction (Nash and Panfilov, 2004; Silva et al., 2020).

### Port-Hamiltonian gyrator coupling

The electrical and mechanical domains are coupled through a skew-symmetric gyrator that guarantees identically zero net power transfer at the interface.  This enforces the First Law of Thermodynamics at machine precision and provides the bidirectional mechano-electrical feedback absent from conventional unidirectional solvers.

### Hypergraph Laplacian

Multi-way cellular interactions are collapsed from an O(N²) dense graph into an O(N) sparse operator via static condensation of a shared trace variable.  The harmonic-mean interfacial conductance correctly models the series-resistance topology of gap-junctional coupling and handles heterogeneous (fibrotic) conductivity without artificial energy creation.

### Metabolic autoregulation

Cells dynamically upregulate their effective reaction rate in proportion to their instantaneous electrotonic load, modelling the physiological source-sink metabolic compensation observed in border-zone myocardium.
